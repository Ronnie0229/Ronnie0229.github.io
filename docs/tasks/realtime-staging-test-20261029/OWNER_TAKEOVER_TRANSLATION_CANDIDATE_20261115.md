# 我们如何在基督的恩典和知识上长进？

我们要一同探究，使徒彼得写下这段话时所表达的意思：“你们却要在我们主救主耶稣基督的恩典和知识上有长进。愿荣耀归给他，从今直到永远！阿们。”（彼得后书 3:18）

基督徒认识并爱耶稣基督，尊祂为救主和主。当我们降服于祂的那一刻，祂的圣灵就充满我们，使我们能够在基督的恩典和知识上长进（约翰福音 14:16、15:26；16:7）。

查尔斯·司布真（Charles Spurgeon）曾说：“当你在我们主救主耶稣基督的恩典和知识上长进时，你必定也会在谦卑上长进。正在成长的基督徒认为自己算不得什么；而完全成熟的基督徒甚至认为自己比一无所有还不如。我们越亲近耶稣，自我就显得越渺小。自我与基督永远无法彼此亲近。当我站在自我身旁时，基督显得渺小；当我站在基督身旁时，自我就显得渺小。”

## 什么是基督的恩典？

恩典的一个广义定义，就是领受我们原本不配得到的东西。1828 年版《韦氏词典》阐述了这个词真实而丰富的含义。其中一项定义是：“恰当地说，恩典就是神白白赐下、人不配得的爱与恩宠，是人从祂那里领受的一切益处的泉源和根源。”（罗马书 11:6）另一项定义是：“将基督的义应用在罪人身上。”（罗马书 5:20）我们本应承受死亡，但我们要赞美神，因为祂白白赐下恩典的礼物。

“因为罪的工价乃是死，唯有神的恩赐，在我们的主基督耶稣里乃是永生。”（罗马书 6:23）

圣经告诉我们：“你们得救是本乎恩，也因着信。这并不是出于自己，乃是神所赐的；”（以弗所书 2:8）就在我们归信、降服于耶稣并尊祂为救主和主的那一刻，圣灵便住在我们里面（约翰福音 14:16–17；罗马书 8:9；哥林多前书 6:19）。从那一刻起，圣灵就使我们成圣（哥林多前书 6:11）。当我们继续探讨对基督的认识时，必须记住：正是圣灵在我们里面作工。

## 什么是对基督的认识？

《贝克福音派词典》告诉我们，在圣经中，“知识不是对信息的占有，而是对信息的实践，或使其成为现实”（箴言 9:10；11:9）。“因此，按照圣经的教导，认识神，并不是以抽象、非人格化的方式知道一些关于祂的事，而是进入祂施行拯救的作为之中（弥迦书 6:5）。认识神，不是从哲学角度探究祂永恒的本质，而是承认并接受祂的要求。这不是某种神秘的默想，而是尽本分的顺服。”我们在祂所赐的能力中顺服，因为我们爱主耶稣，并为祂为我们所成就的一切心存感恩、满有喜乐。

圣经告诉我们，主神是不可测透的（约伯记 11:7–9；以赛亚书 55:8–9；罗马书 11:33）。我们这些心智有限的人必须接受这一事实。祂是神，我们不是。我们永远无法完全认识祂，也就是说，我们不可能对祂有完全的认识。

但这是否意味着我们完全无法认识祂呢？答案响亮而明确：“不是。”

约翰福音 1:14 告诉我们：“道成了肉身，住在我们中间，充充满满地有恩典有真理。我们也见过他的荣光，正是父独生子的荣光。”（约翰福音 1:14）约翰福音 1:18 又说：“从来没有人看见神，只有在父怀里的独生子将他表明出来。”因为耶稣的缘故，我们这些相信祂、爱祂的人，可以毫无阻隔地来到父面前，并借着基督认识父神（约翰福音 14:8–14）。

每一位在基督里的信徒都蒙召归向祂（约翰福音 14:6；罗马书 8:29–30）。主神愿意我们认识祂；我们从祂所创造的万物中知道祂确实存在（诗篇 19:1–6；罗马书 1:18–20）。然而，祂赐下耶稣基督，作为祂对自身最伟大的启示（约翰福音 1:14）。

现在，让我们再次看看备受尊崇的诺亚·韦伯斯特（Noah Webster）所说的话：“对于不存在的事物，我们不可能有任何认识。神对祂的一切作为都有完全的认识。人的知识十分有限，而且大多来自观察和经验。”要获得神借着祂的话语和主耶稣基督所启示的关于祂的认识，仅靠观察是不够的。因为我们是有限的人，祂就差来一位帮助者，将我们凭自己绝不可能具备的悟性赐给我们；这位帮助者就是圣灵。

主在祂的话语中这样告诉我们：

“因为耶和华赐人智慧， 知识和聪明都由他口而出。”（箴言 2:6）

诗篇 19:7–14 使我们得以认识神的律法。若没有祂的灵住在我们里面，我们绝不可能明白这律法。我们必须记住，正是圣灵在我们里面作工。祂开启我们的心，使我们领会主的恩典；也正是祂使我们认识那位圣者（箴言 9:10）。

## 那么，我们应当怎样在基督的恩典和知识上长进？

既然知道，是圣灵在我们里面作工，使我们能够明白主的恩典是什么、认识祂意味着什么，那么我们就可以通过以下方式在祂的恩典和知识上长进：

成为一间传讲福音的教会的会友，并定期参加聚会。这间教会应当阐明并颂扬基督的全然充足。

经常领受通常的施恩之道（读经与讲道、祷告，以及主餐）。每一个主日，基督都以祂的恩典服事我们。我们思想祂和祂所成就的事；当我们来到主的桌前时，是为了记念祂（路加福音 22:19）。我们专注于基督，而不是自己；我们也知道，恩典不是我们能够使之增长的东西，因为恩典来自神，而且其分量无限。神源源不断、毫无限量地将祂的恩典赐给我们。要欢喜领受。

在这恩典的时代顺服圣灵（罗马书 8:14–17；约翰福音 1:17；罗马书 6:14）。我们的行为不能救我们。圣灵吸引我们归向主（约翰福音 6:44）；圣灵引导我们（约翰福音 16:13）、教导我们（约翰福音 14:26），也使我们知罪（约翰福音 16:8–11）。祂教导我们认识基督，也恢复我们的意志。圣灵感动我们、赐给我们能力，使我们接纳那位白白赐给我们的耶稣基督。

要认识到，福音不只是圣经中的某一段经文。耶稣基督就是福音。罗马书 1:16–17 说：“我不以福音为耻，这福音本是神的大能，要救一切相信的，先是犹太人，后是希腊人。因为神的义正在这福音上显明出来，这义是本于信以至于信，如经上所记：‘义人必因信得生。’”我们所信靠的不是自己的信心；我们信靠的是基督，以及祂为我们并在我们里面所成就的完美工作。

在基督的恩典和知识上长进，是我们成圣过程的一部分。我们这些有罪的人，总想靠自己做事，或按照自己的方式行事。但神并没有命定我们以这样的方式成长。

每一个主日，基督都向我们倾注祂的恩典。许多教会把律法与福音混为一谈，使会众以为我们必须靠行为来维持救恩，或证明自己已经得救。当耶稣吩咐那位富有的少年官去照样行的时候，祂是在向他陈明律法。除了基督以外，没有人曾完全遵守律法。我们从来没有尽心、尽意、尽性、尽力地爱主我们的神。正因如此，我们需要祂的恩典。我们需要不断有人向我们宣讲福音，好让基督为我们所成就的一切深深进入我们的心，使我们安息在祂完全的义中。

## 去吧，继续长进

在祂的恩典上长进，意味着我们每周与教会一同聚集时，都领受祂的恩典。

在祂的恩典上长进，意味着我们领受主餐时，思想耶稣和祂所成就的事。

既然神亲自住在我们里面，充满我们、使我们成圣，并使我们在耶稣基督的恩典和知识上长进（以西结书 36:26–27；约翰福音 6:44–45），我们为什么还要试图单靠自己来做这一切呢？祂的话语说：“那在你们心里动了善工的必成全这工，直到耶稣基督的日子。”（腓立比书 1:6 下）这是神在我们里面所做的工，而祂总会成就自己的旨意。

所以，去吧，靠着主的灵在你们里面运行的大能，不断长进。
