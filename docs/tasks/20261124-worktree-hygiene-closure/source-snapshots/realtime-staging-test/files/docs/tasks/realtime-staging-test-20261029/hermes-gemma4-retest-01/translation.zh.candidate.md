如何在基督的恩典与知识中增长？
我们受伤要发现使徒彼得在写下那句话时所表达的意思：“你们要在我们主并救主耶稣基督的恩典与知识上增长，直到永恒之日。愿荣耀归给祂，现在是时候，直到永恒。阿们”（彼得后书 3:18）。基督徒认识并爱耶稣基督，祂是我们的救主与主。当我们向祂俯伏顺服的那一刻，祂的圣灵就充满了我们，使我们能够在基督的恩典与知识中增长（约翰福音 14:16, 15:26; 16:7）。
 
查尔斯·司布力更是曾说：“当你在这位我们主并救主耶稣基督的恩典与知识中增长时，你必定会在谦卑中增长。成长的基督徒认为自己微不足足，但成熟的基督щу基督徒认为自己甚至不如虚无；随着我们越发接近耶稣，自我（self）就会显得越发渺小。自我与基督永远无法亲近。当我站在自我身旁时，基督显得很小；而当我站在基督身旁时，自我便显得微小。”
 
什么是基督的恩典？
对恩典的一个广泛定义是接受我们不配得的。韦伯斯特 1828 年的词典分享了其含义中真实而多样的细微差别。其一，它将恩典描述为：“恰切地，指上帝那白白施予、不求回报的爱与恩宠，是人从祂那里获得一切益处的源头与泉源”（罗马书 11:6）。其二，“是指基督的义应用在罪人身上”（罗马书 5:20）。我们罪有应得，却为祂白白施予的恩典之礼而称颂上帝。
 
“因为罪的工价乃是死；惟有上帝的恩赐，是在基督耶稣我们主里的永生”（罗马书 6:23）。
 
圣经告诉我们：“你们本是因恩典藉着信得以救恩；这并不是出于自己，乃是上帝的恩赐”（以弗所书 2:8）。就在皈依的那一刻，当我们向耶稣作为救主与主俯伏时，圣灵就内住在我们里面（约翰福音 14:16-17; 罗马书 8:9; 哥林多前书 6:19）。从那一刻起，圣灵便使我们成圣（哥林多前书 6:11）。祂是那在我们里面作工的一位，记住这个真理，当我们向着前方迈进并寻求认识基督时，这一点至关重要。
 
什么是基督的知识？
贝克尔福音派词典告诉我们，在圣经中，“知识并非信息的占有，而更是在其间的践行或使之成为现实”（箴言 9:10; 11:9）。“因此，从圣经的角度来看，认识上帝并不是以一种抽象且非人格化的方式去了解祂，而是进入祂拯救的作为之中（弥迦书 6:5）。认识上帝不是与祂永恒的本质进行哲学上的纠葛，而是承认并接受祂的主权。它不是某种神秘的沉思，而是尽职的顺服。”我们因着蒙恩而顺服，是因为我们爱我们的主耶稣，并为祂为我们所成就的事而满怀感恩与喜乐。
 
圣经告诉我们，主上帝是不可理喻的（约伯记 11:7-9; 以赛亚书 55:8-9; 罗马书 11:33），而我们这些有限心智的人必须接受这一点。祂是上帝，我们不是。我们永远无法拥有关于祂的全备知识，即完全地认识祂。
 
但祂是不可知的吗？响亮的回答是：“不是。”约翰福音 1:14 告诉我们：“道成了肉身，住在我们中间，我们也见过祂的荣耀，正是父独生子的荣耀，充满了恩典与真理”（约翰福音 1:14）。约翰福音 1:18 指出：“从来没有人见过上帝；在父怀里的独生子，祂将祂彰显出来。”因为有了耶稣，我们这些信靠并爱祂的人，可以毫无阻碍地亲近父，并借着基督认识祂（约翰福音 14:8-14）。
 
每一位在基督里的信徒都被呼召归向祂（约翰福音 14:6; 罗马书 8:29-30）。主上帝希望我们认识祂，而我们从祂的创造中知道祂的存在（诗篇 19:1-6; 罗马书 1:18-20）。然而，祂已将耶稣基督赐给我们，作为祂自己最伟大的启示（约翰福音 1:14）。
 
我们再次看那受人尊敬的诺亚·韦伯斯特所说：“我们无法对不存在的事物拥有知识。上帝对祂所有的作为都有完美的认知。人的知识是非常有限的，且大多是通过观察与经验获得的。”要获得上帝通过祂的话语和主耶稣基督所启示的知识，不仅仅需要观察。因为我们是有限的，祂便差遣了一位保惠师来赐给我们我们靠自己绝不可能获得的理解力——那就是圣灵。
 
主在祂的话语中这样告诉我们：
 
“因为耶和华赐智慧；从祂口中发出知识与悟性”（箴言 2:6）。
 
诗篇 19:7-14 让我们洞察上帝的律法。若没有祂内住的灵，我们永远无法理解。我们需要记住，是在我们里面作工的是圣灵。祂向我们的心敞开以领受主的恩典，祂使我们得以认识那神圣的一位（箴言 9:10）。
 
因此，我们如何在这份基督的恩典与知识中增长？
深知是在我们里面作工的圣灵使我们得以领悟主的恩典与知识，因此我们可以通过以下方式在祂的恩典与知识中增长：
 
成为一家传福音教会的成员并定期参加，这类教会宣讲并颂扬基督的充足性。
 
定期领受普通的恩典手段（读经与讲道、祷告，以及圣餐）。每个主日，我们都被基督的恩典所服侍。我们默想祂及祂所成就的事，当我们来到主的桌前，我们以此纪念祂（路加福音 22:19）。我们聚焦于基督而非自我，我们知道恩典并非我们能“增长”的东西，因为它来自上帝，且在量上是无穷的。上帝以无尽的流淌将恩典延伸到我们身上。要满怀喜乐地领受。
 
在这个恩典时代向圣灵顺服（罗马书 8:14-17; 约翰福音 1:17; 罗马书 6:14）。我们的行为救不了我们。圣灵引导我们归向主（约翰福音 6:44），圣灵引导我们（约翰福音 16:13），教导我们（约翰福音 14:26），并使我们觉察过犯（约翰福音 16:8-11）。祂在认识基督的知识上教导我们，祂使我们的意志重焕生机。圣灵感化并赋能我们，使我们欢然迎接耶稣基督作为那白白施予的救主。
 
意识到福音不仅仅是经文中的一段。耶稣基督就是福音。罗马书 1:16-17 阐述道：“我也不以福音为耻；因为这福音是上帝的大能，要在犹太人身上，也在希腊人身上，把神的义显明出来，使一切相信的，就藉着信得着义。正如经上所记：『义人必因信得生。』”我们对信仰本身并不抱有信心，我们是信靠基督及其在我们身上、为我们所成就的完美工作的。
 
在基督的恩典与知识中增长是圣洁过程的一部分。我们作为有罪的人，总想凭着自己或自己的方式行事。但这并不是上帝所命定的增长方式。
 
每个主日都是基督的恩典向我们倾注的过程。许多教会将律法与福音混为一谈，使会众觉得我们必须通过行为来维持或证明救恩。当耶稣对那个财力雄厚的青年统治者说话时，祂是在向他传讲律法。在基督之外的人从未守住律法。我们从未全心全意、尽心、尽性、尽力地爱我们的主上帝。这就是为什么我们需要祂的恩典。我们需要持续地向我们宣讲福音，使基督为我们所做的事在我们心中扎根，并安息在祂完美的义中。
 
去吧，并增长
在祂的恩典中增长，意味着在我们聚会时，每周都领受祂的恩典。在祂的恩典中增长，意味着当我们领受主餐时，反思耶稣及祂所成就的事。
 
既然上帝亲自充满我们、使我们成圣，并使我们在耶稣基督的恩典与知识中增长（以西结书 36:26-27; 约翰福音 6:44-45），我们为何还要靠自己尝试这一切呢？祂的话语说：“那在你们心里动了善工的，必成全这工，直到耶稣基督的日子”（腓立比书 1:6b）。这是上帝在我们里面作工，祂总会成就祂的目的。
 
因此，愿主灵的力量在你们里面作工，去吧，并增长。
