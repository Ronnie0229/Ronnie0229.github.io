什么是对基督的认识？
《贝克福音派神学词典》（Baker’s Evangelical Dictionary）告诉我们，在圣经中，“知识并不是对信息的占有，而是对信息的运用，或使其付诸实践”（箴言 9:10；11:9）。
该词典进一步指出：“因此，按照圣经的教导，认识神，并不是以一种抽象、非人格化的方式知道一些关于祂的事，而是参与祂施行拯救的作为（弥迦书 6:5）。认识神，并不是从哲学角度试图探究祂永恒的本质，而是承认并接受祂的要求。这不是某种神秘的默想，而是尽本分的顺服。”
我们之所以顺服，是因为我们爱我们的主耶稣，并且因祂为我们所成就的一切而心怀感恩与喜乐。而我们能够顺服，也是因为祂赐给我们顺服的能力。
圣经告诉我们，主神是我们无法完全测透的（约伯记 11:7–9；以赛亚书 55:8–9；罗马书 11:33）。我们这些心智有限的人必须接受这一事实。祂是神，我们不是。我们永远无法对祂拥有完全的认识，也就是说，我们不可能彻底认识祂。
但这是否意味着我们根本无法认识祂呢？
答案是响亮的：“不是。”
约翰福音 1:14 告诉我们：
“道成了肉身，住在我们中间，充充满满地有恩典有真理。我们也见过他的荣光，正是父独生子的荣光。”（约翰福音 1:14）
约翰福音 1:18 又说：
“从来没有人看见神，只有在父怀里的独生子将他表明出来。”（约翰福音 1:18）
因为耶稣的缘故，我们这些相信祂、爱祂的人，可以毫无阻碍地来到父面前，并借着基督认识父神（约翰福音 14:8–14）。
每一位在基督里的信徒都蒙召归向祂（约翰福音 14:6；罗马书 8:29–30）。主神愿意我们认识祂。我们从祂所创造的万物中，就能够知道祂确实存在（诗篇 19:1–6；罗马书 1:18–20）。然而，祂更赐下耶稣基督，作为祂对自身最伟大的启示（约翰福音 1:14）。
现在，让我们再次看看备受尊敬的诺亚·韦伯斯特（Noah Webster）所说的话：
“对于不存在的事物，我们不可能拥有任何认识。神对祂一切的作为都有完全的认识。人的知识却十分有限，而且大多来自观察和经验。”
要获得神借着祂的话语和主耶稣基督所启示的、对神的认识，仅靠观察是不够的。
因为我们是有限的人，神就差来一位帮助者，将我们凭自己绝不可能获得的悟性赐给我们。这位帮助者就是圣灵。
主在祂的话语中这样告诉我们：
“因为耶和华赐人智慧， 知识和聪明都由他口而出。”（箴言 2:6）
诗篇 19:7–14 使我们明白神律法的奥妙。如果没有祂的灵住在我们里面，我们就永远无法理解祂的律法。
我们必须记住，正是圣灵在我们里面作工。祂开启我们的心，使我们能够领受主的恩典；也正是祂使我们得以认识那位圣者（箴言 9:10）。
