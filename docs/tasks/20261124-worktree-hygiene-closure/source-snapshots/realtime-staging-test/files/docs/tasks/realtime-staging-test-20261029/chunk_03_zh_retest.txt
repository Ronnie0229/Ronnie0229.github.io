那么，我们如何在基督的恩典和知识上长进？

既然我们知道，是圣灵在我们里面作工，使我们能够明白主的恩典是什么，以及认识祂意味着什么，那么我们就可以通过以下方式，在祂的恩典和知识上不断长进：

成为一间传讲福音的教会的会友，并定期参加聚会。这间教会应当阐明并颂扬基督的完全充足。

经常领受通常的施恩途径，包括读经、讲道、祷告和主餐。每一个主日，基督都以祂的恩典服事我们。我们思想祂以及祂所成就的一切；当我们来到主的桌前领受主餐时，我们是为了记念祂（路加福音 22:19）。

我们专注于基督，而不是自己。我们也知道，恩典并不是我们能够使之增长的东西，因为恩典来自神，而且是无限的。神将祂的恩典无穷无尽地赐给我们。我们应当满怀喜乐地领受。

在这个恩典的时代顺服圣灵（罗马书 8:14–17；约翰福音 1:17；罗马书 6:14）。我们的行为不能拯救我们。圣灵吸引我们归向主（约翰福音 句6:44）；圣灵引导我们（约翰福音 16:13）、教导我们（约翰福音 14:26），并使我们知罪（约翰福音 16:8–11）。

祂教导我们认识基督，也恢复我们的意志。圣灵感动我们，赐给我们能力，使我们愿意接受那位白白赐下的耶稣基督。

要认识到，福音远不止圣经中的某一段经文。耶稣基督就是福音。

罗马书 1:16–17 说：

“我不以福音为耻，这福音本是神的大能，要救一切相信的，先是犹犹太人，后是希腊人。因为神的义正在这福音上显明出来，这义是本于信以至于信，如经上所记：‘义人必因信得生。’”（罗马书 1:16–17）

我们所信靠的不是自己的信心。我们所信靠的是基督，以及祂为我们、在我们里面所成就的完全之工。

在基督的恩典和知识上长进，是我们成圣过程的一部分。我们这些有罪的人，总想靠自己做事，或按照自己的方式行事。但神并没有命定我们以这样的方式成长。

每一个主日，基督都向我们倾注祂的恩典。

许多教会把律法和福音混为一谈，使会众以为，我们必须靠行为来维持自己的救恩，或证明自己已经得救。

当耶稣吩咐那位富有的年轻官长去照样行的时候，祂是在向他讲明律法。

除了基督以外，从来没有人能够完全遵守律法。我们从来没有尽心、尽意、尽性、尽力地爱主我们的神。

正因如此，我们需要祂的恩典。我们需要不断有人向我们宣讲福音，好让基督为我们所成就的一切深深进入我们的心，使我们能够安息在祂完全的义中。

去吧，并且不断长进

在祂的恩典上长进，意味着我们每周与教会一同聚集时，都领受祂的恩典。

在祂的恩典上长进，意味着我们领受主餐时，思想耶稣以及祂所成就的一切。

既然神亲自住在我们里面，充满我们，使我们成圣，并使我们在耶稣基督的恩典和知识上长进（以西结书 36:26–27；约翰福音 6:44–45），我们为什么还要试图单靠自己来做这一切呢？

祂的话语说：“那在你们心里动了善工的必成全这工，直到耶稣基督的日子。”（腓立比书 1:6 下）

这是神在我们里面所做的工，而祂总是会成就自己的旨意。

所以，去吧！靠着主的灵在你们里面运行的大能，不断长进。
