我们如何在基督的恩典和知识上长进？

我们将一起探究使徒彼德写下这段话时所表达的意思：“你们却要在我们主救主耶稣基督的恩典和知识上有长进。愿荣耀归给他，从今直到永远！阿们。”（彼得后书 3:18）

基督徒认识并爱耶稣基督，尊祂为救主和主。当我们降服于祂的那一刻，祂的圣灵就充满我们，使我们能够在基督的恩典和知识上长进（约翰福音 14:16、15:26；16:7）。

查尔斯·司布真（Charles Spurgeon）曾说：“当你在我们主救主耶稣基督的恩典和知识上长进时，你必定也会在谦卑上长进。正在成长的基督徒认为自己算不得什么，而成熟的基督徒甚至认为自己比什么都不是还要不如。我们越亲近耶稣，自我就显得越渺小。自我与基督永远无法彼此亲近。当我站在自我身旁时，基督就显得渺小；当我站在基督身旁时，自我就显得渺小。”

什么是基督的恩典？

恩典的一个广义定义，就是领受我们原本不配得到的东西。1828 年版《韦氏词典》对恩典一词真实而丰富的含义作出了多方面的阐释。其中一个定义是：“准确地说，恩典就是神白白赐下、人原本不配得的爱与恩宠，是人从祂那里领受一切益处的泉源和根本。”（罗马书 11:6）另一个定义是：“将基督的义归给罪人。”（罗马书 5:20）

我们本应承受死亡，但感谢赞美神，因为祂白白赐给我们充满恩典的礼物。

“因为罪的工价乃是死，唯有神的恩赐，在我们的主基督耶稣里乃是永生。”（罗马书 6:23）

圣经告诉我们：“你们得救是本乎恩，也因着信。这并不是出于自己，乃是神所赐的；”（以弗所书 2:8）

就在我们归信、降服于耶稣并尊祂为救主和主的那一刻，圣灵便住在我们里面（约翰福音 14:16–17；罗马书 8:9；哥林多前书 6:19）。从那一刻起，圣灵就开始使我们成圣（哥林多前书 6:11）。

正是圣灵在我们里面作工。当我们继续往下探讨对基督的认识时，记住这一真理至关重要。
